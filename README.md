# Yoten — новостная лента

Личный агрегатор новостей: RSS с 30+ изданий → AI-саммари на русском (короткое
для ленты + подробное для модалки) → категоризация по темам → дедупликация
одинаковых новостей от разных изданий по смысловой похожести. Фронтенд —
минималистичная лента карточек на Next.js в духе редакторских изданий вроде
Kinfolk, без авторизации.

## Возможности

- **30+ источников** — от NYT и BBC до IGN и Rolling Stone (полный список —
  `src/config/sources.ts`), новости за сегодня (настраивается).
- **AI-саммари на русском** — короткое (2-3 предложения) для ленты и подробное
  (5-8 предложений) для модального окна, оба — самостоятельный пересказ своими
  словами, не перевод оригинала.
- **Категории** — технологии, искусство, игры, авто, путешествия, экономика,
  политика, происшествия, здоровье, другое; статья может относиться сразу к
  двум темам. Спорт распознаётся, но полностью исключён из ленты.
- **Дедупликация** — одинаковые новости от разных изданий (или повторные от
  одного) склеиваются в одну карточку с "+N источника" вместо дублей в ленте.
- **Защита от выдумывания фактов** — модели явно запрещено добавлять детали,
  которых нет в исходном тексте; если материала слишком мало, она честно
  сокращает ответ вместо того, чтобы дописывать за счёт общих знаний.

## Быстрый старт

```bash
npm install
cp .env.example .env   # заполнить DATABASE_URL и GEMINI_API_KEY
npm run db:init         # применит схему и добавит источники
npm run fetch            # соберёт и обработает сегодняшние новости
npm run dev               # http://localhost:3000
```

### Postgres с pgvector

Проще всего через [Neon](https://neon.tech) или [Supabase](https://supabase.com)
(оба бесплатны для старта) — создать проект, включить расширение `vector`
(или это сделает `npm run db:init`) и скопировать connection string в
`DATABASE_URL`.

### Саммаризация: Gemini (по умолчанию) или Groq

Ключ Google AI Studio — [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
→ `GEMINI_API_KEY`. Бесплатный тариф ограничен **per-project-per-model**
(от 15-20 до нескольких сотен запросов в день/минуту в зависимости от
модели) — при `RESOURCE_EXHAUSTED` просто смени `GEMINI_MODEL` на другую
(своя отдельная квота) или задай `GEMINI_API_KEY_2` от второго проекта
(полностью независимый лимит).

Альтернативный провайдер — [Groq](https://console.groq.com/keys)
(`GROQ_API_KEY`, `src/lib/groq.ts`, модель `qwen/qwen3.8-27b`): щедрые
лимиты по минутам, но свой дневной потолок по токенам. Переключается
подменой импорта в `src/lib/summarizer.ts`.

## Архитектура пайплайна (`src/jobs/fetchAndProcess.ts`)

Для каждой новой статьи (по `link`, дубликаты по URL пропускаются):

1. **Извлечение текста статьи** (`src/lib/ogTags.ts`), по убыванию
   надёжности:
   1. Ручной CSS-селектор для конкретного издания (`contentSelector` в
      `src/config/sources.ts`), если задан — через `cheerio`.
   2. **JSON-LD `articleBody`** (schema.org) — самый чистый источник, когда
      есть (Wired, The New Yorker, The Verge, Condé Nast-издания).
   3. Абзацы внутри самого большого тега `<article>` на странице — отсекает
      общее меню/сайдбар сайта, если структура страницы это позволяет.
   4. Абзацы по всей странице (эвристика по длине и плотности пробелов) —
      запасной вариант, если `<article>` не помог или отсутствует.
   
   Часть изданий (NYT, Telegraph, Bloomberg, WSJ, Economist, GameSpot)
   блокируют такие запросы — для них остаётся только тизер из RSS.

2. **Саммаризация** (`src/lib/summarizer.ts`) — пробует источники контекста
   по убыванию качества, откатываясь на более простой при сигнале
   `NO_CONTENT` от модели (мусор на входе или фактов действительно нет).
   Подробное саммари для модалки **не генерируется вовсе**, если нет
   реального текста статьи (только тизер из RSS) — на голом тизере модель
   регулярно "дописывала" недостающий объём за счёт общих знаний.

3. **Эмбеддинг** (`src/lib/embeddings.ts`, Xenova/all-MiniLM-L6-v2, локально)
   — считается от **оригинального текста статьи**, а не от саммари: короткий
   унифицированный пересказ теряет специфику, из-за которой разные новости на
   одну тему становятся неотличимы по смыслу от настоящих дублей.

4. **Кластеризация** (`src/lib/grouping.ts`) — сравнение только с "якорями"
   (ещё не приклеенными ни к чему статьями) в окне 12 часов, чтобы избежать
   транзitivной склейки (A~B~C, хотя A и C не связаны) и не давать старым
   статьям бесконечно притягивать новые. Источник может быть любым, включая
   тот же самый. `DEDUPE_THRESHOLD=0.75` — на реальных примерах настоящие
   дубли дают похожесть 0.79-0.85, разные новости на одну тему — 0.53-0.67.

## Фронтенд

Next.js App Router, лента карточек одной колонкой: картинка сверху (если
есть), текст саммари, "+N источника" при склейке. Клик открывает модалку
(bottom sheet) с подробным пересказом и ссылками на все источники. Фильтр по
категориям в шапке, бесконечная подгрузка по кнопке "Показать ещё". Данные —
`src/lib/feed.ts`, тот же код отдаёт JSON по `GET /api/feed`.

Оформление: кремовый/белый фон, книжная антиква Lora для заголовков, гротеск
Onest для текста новости, акцент — терракотовый `#C94F3D` (цвет логотипа).
Без тёмной темы.

## Скрипты

| Команда | Назначение |
|---|---|
| `npm run fetch` | Собрать и обработать сегодняшние новости по всем источникам |
| `npm run feed` | Вывести готовую ленту в консоль |
| `npm run dev` / `build` / `start` | Next.js фронтенд |
| `npm run db:init` | Применить схему БД + добавить источники из конфига |
| `npm run backfill-og` | Досчитать картинку/текст для уже собранных статей |
| `npm run backfill-categories` | Досчитать категории для статей без них |
| `npm run resummarize` | Пересчитать саммари (напр. после правки промпта) |
| `npm run upgrade-quality` | Пересчитать саммари с полным текстом вместо тизера |

## Известные ограничения

- NYT и Telegraph блокируют скрапинг страницы — обход защиты сознательно не
  делается, это противодействие мерам издания, а не чтение публичных данных.
- Индекс `ivfflat`/`hnsw` на `embedding` намеренно не используется — при
  текущем объёме данных (retention в днях) точный скан надёжнее.
- Бесплатная квота Gemini/Groq — основной практический потолок пропускной
  способности пайплайна; см. `GEMINI_API_KEY_2` и переключение модели/провайдера выше.
